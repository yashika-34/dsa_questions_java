| Topic | Description |
|---|---|
| 📦 Arrays | Array manipulation, searching, and problem-solving |
| 🔗 Linked Lists | Insertion, deletion, traversal, and linked list problems |
| 📚 Stack | Stack operations and stack-based problems |
| 🔤 Strings | String manipulation and character-based problems |
| 🌳 Trees | Tree traversal and binary tree problems |
| ⛰️ Heaps | Heap insertion, deletion, peek, build heap, heapify, and heap sort |
| 🔄 Recursion | Recursive approaches to common programming problems |

## ▶️ How to Run the Code

**1. Clone the repository**

```bash
git clone https://github.com/yashika-34/dsa_questions_java.git
```

**2. Navigate to the project directory**

```bash
cd dsa_questions_java
```

**3. Compile a Java file**

```bash
javac FileName.java
```

**4. Run the program**

```bash
java FileName
```

Replace `FileName` with the class name of the Java program you want to execute. If a program uses a package such as `com.chitkara`, compile and run it from the appropriate source root.
